One-time setup — free forever

Steps (takes ~3 minutes):
1. Go to console.firebase.google.com → Create project
2. Project settings → Add web app → copy the firebaseConfig object
3. Build → Firestore Database → Create (start in test mode)
4. Authentication → Sign-in method → enable Google
5. Paste your config below and click Connect
